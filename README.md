# Nexus Academic — Academia–Industry Collaboration Portal

A full-stack prototype for **"Portal for Academia–Industry Collaboration for Skill Mapping, Internships and Placement"** (SIH Problem Statement).

---

## 🏗️ Architecture

```
/SIH
  /backend               ← NestJS + Prisma + PostgreSQL (this folder)
  /stitch_academia_industry_collaboration_hub  ← Static frontend HTML pages
```

## 🚀 Quick Start (One-Time Setup)

### Prerequisites
- Node.js ≥ 18  ✅ (already installed: v24)
- npm  ✅

### 1. Install & Initialize (run once)

```bash
cd /path/to/SIH/backend
npm run setup
```

This runs:
1. `npm install` — installs all dependencies
2. `npm run db:init` — starts embedded PostgreSQL + writes `.env`
3. `npm run db:push` — applies Prisma schema to the DB
4. `npm run db:seed` — loads demo data

### 2. Start the Backend

```bash
npm run dev
```

API runs at: **http://localhost:3001/api/v1**  
Swagger docs: **http://localhost:3001/api**

### 3. Open the Frontend

Open any HTML page directly in your browser, e.g.:
```
file:///path/to/SIH/stitch_academia_industry_collaboration_hub/nexus_academic_landing_page/code.html
```

Or use VS Code Live Server on the frontend folder (port 5500).

## 📋 Environment Variables (`.env`)

Auto-generated by `npm run db:init`. Variables:

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | PostgreSQL connection string |
| `JWT_SECRET` | JWT signing secret |
| `JWT_REFRESH_SECRET` | Refresh token signing secret |
| `JWT_EXPIRES_IN` | Access token TTL (default: 7d) |
| `PORT` | Backend port (default: 3001) |
| `FRONTEND_URL` | Allowed CORS origin |
| `EMBEDDED_PG_*` | Embedded PostgreSQL configuration |

## 📡 API Routes Summary

### Auth (`/api/v1/auth`)
| Method | Path | Description |
|--------|------|-------------|
| POST | `/register` | Register (Student/Industry/Academician/Admin) |
| POST | `/login` | Login, returns JWT + refresh token |
| POST | `/onboarding` | Complete profile onboarding |
| POST | `/refresh` | Refresh access token |
| POST | `/logout` | Invalidate refresh token |

### Users (`/api/v1/users`)
| GET | `/me` | Get current user + profile |
| PUT | `/me` | Update profile |

### Assessments (`/api/v1/assessments`)
| GET | `/templates` | Get active questionnaire |
| POST | `/submit` | Submit answers + compute skill profile |
| GET | `/skill-profile/:studentId` | Get skill profile + gap report |
| GET | `/recommendations/:studentId` | Get job role + course recommendations |

### Internships (`/api/v1/internships`)
| GET | `/` | Search/filter listings |
| POST | `/` | Create posting (Industry) |
| GET | `/:id` | Posting detail |
| PUT | `/:id` | Update posting |
| DELETE | `/:id` | Close posting |
| POST | `/:id/apply` | Student applies |
| GET | `/:id/candidates` | Ranked candidate list (Industry) |
| PATCH | `/applications/:id/status` | Update application status |
| GET | `/my-applications` | Student's application tracker |

### Learning Programs (`/api/v1/learning-programs`)
| GET | `/` | Browse all programs |
| POST | `/` | Publish program (Industry) |
| POST | `/:id/enroll` | Enroll (Student) |
| PATCH | `/:id/complete` | Mark complete + auto-issue certificate |
| GET | `/my-enrollments` | Student's enrolled courses |

### Analytics (`/api/v1/analytics`)
| GET | `/student/dashboard` | Student dashboard data |
| GET | `/industry/dashboard` | Industry dashboard data |
| GET | `/academician/dashboard` | Academician dashboard data |
| GET | `/institution/dashboard` | Institution admin dashboard data |

### Academicians (`/api/v1/academicians`)
| GET | `/fdps` | List FDP opportunities |
| GET | `/research-collaborations` | List research opportunities |
| POST | `/research-collaborations` | Post new opportunity |
| GET | `/workshops` | Upcoming workshops |
| POST | `/workshops` | Create workshop |
| GET | `/student-progress` | Monitor student progress |

### Notifications (`/api/v1/notifications`)
| GET | `/` | All notifications |
| GET | `/unread-count` | Unread count |
| PATCH | `/:id/read` | Mark read |
| PATCH | `/mark-all-read` | Mark all read |

### Messages (`/api/v1/messages`)
| GET | `/conversations` | All conversations |
| GET | `/conversations/:id` | Messages in conversation |
| POST | `/conversations/:id` | Send message |
| POST | `/start` | Start conversation |

### Admin (`/api/v1/admin`) — Institution Admin only
| GET | `/users` | List all users |
| PATCH | `/users/:id/status` | Activate/suspend user |
| GET | `/verifications` | Pending verifications |
| PATCH | `/verifications/industry/:id` | Approve/reject industry |
| PATCH | `/verifications/certificate/:id` | Verify certificate |

### Portfolio (`/api/v1/portfolio`)
| GET | `/me` | Current student portfolio |
| GET | `/:studentId` | Portfolio by student ID |

### Uploads (`/api/v1/uploads`)
| POST | `/` | Upload file (resume, certificate, report) |

### Industry (`/api/v1/industry`)
| GET | `/profile` | Current industry profile |
| PUT | `/profile` | Update profile |
| GET | `/my-postings` | All postings by current company |
| GET | `/my-programs` | Learning programs by current company |
| GET | `/:id/profile` | Public company profile |

| Local `/uploads` | AWS S3 / Cloudflare R2 |
| Console OTP logging | SendGrid / Twilio |
| Polling notifications | WebSockets (Socket.io) |
| In-memory matching | Elasticsearch / vector search |
